# Cross-Asset Trend Following — a research implementation

跨资产时序动量（time-series momentum / trend following）的研究实现：数据、信号、
组合构建、成本、回测、归因、稳健性与容量，全部可复现。

这个仓库是**证据**，不是文章。`reports/` 里的图表与结论由 `run.py` 一次跑出，
改动任何一个参数都会重新生成全部结果与 run manifest。

## 一条命令复现

```bash
python run.py --config config/base.yml --out reports/
```

输出：

```
data/raw/            下载的原始日频数据（parquet，含抓取日期）
data/processed/      收益面板、波动、信号、权重、净值
reports/manifest.json  git hash、config hash、数据 hash、运行时间
reports/exhibits/*.svg 图表
reports/results/*.csv  结果表
```

第一次运行会联网抓取数据并缓存到 `data/cache/`；之后不再联网。

## 结构

| 目录 | 内容 |
|---|---|
| `config/` | 全部参数（资产池、信号、组合、成本、回测窗口）。代码里不写死数字 |
| `src/catrend/` | 计算引擎：数据、信号、组合、回测、评估、绘图 |
| `notebooks/` | 研究过程与解释。**只读 `reports/results/` 的结果，不产出最终数字** |
| `tests/` | 未来函数（look-ahead）、成本恒等式、权重约束的单元测试 |
| `reports/` | 图表、结果表、run manifest |

## 研究口径（必须先读，再看数字）

- **数据**：ETF 复权价（含分红），日频，2007-01 起。用 ETF 而非连续期货，
  是为了避免 roll 价差污染收益；代价是样本短、且无法做空。
  长样本（2001 年起、连续期货）在 v2 作为稳健性检验，roll 问题会单独披露。
- **无未来函数**：月末用截至当日收盘的数据算信号与权重，**下一交易日**才生效。
  `tests/test_no_lookahead.py` 用力导数据证明这一点。
- **成本**：`sum |Δw| × 单向 bps(资产类别)`，按再平衡日扣。turnover 用两向口径
  （`0.5 × sum |Δw|`）。关税、融资、借券成本已计入清单但默认 0，可配置。
- **结论的边界**：这不是实盘，是研究实现。所有"净收益"都依赖成本假设，
  所以每张收益图都配一张 break-even 成本图。

## v1 资产池

11 个流动性最好的 ETF 代理，覆盖股票 / 利率 / 黄金 / 商品 / 外汇 / 房地产：
SPY、EFA、EEM、IEF、TLT、GLD、DBC、UUP、FXE、FXY、VNQ。

## v1 结果（净口径，含成本；样本 2007-03 → 2026-10）

| 组合 | 年化 | 波动 | Sharpe | 最大回撤 | 两向换手/年 |
|---|---|---|---|---|---|
| 趋势（多空，目标波动 10%） | 3.49% | 9.24% | 0.38 | −24.5% | 3.65× |
| 趋势（只做多） | 6.15% | 10.54% | **0.58** | −23.6% | 2.78× |
| 60/40 | 8.26% | 11.01% | **0.75** | −32.2% | 0.12× |
| 11 资产等权 | 4.77% | 8.92% | 0.53 | −27.8% | 0.18× |

三条结论（详细论证见 [`reports/research_note.md`](reports/research_note.md)）：

1. **信号有效但很薄**：`sign(12 个月动量)` 对未来 21 日方向的命中率约 53%，30 组参数全为正。
2. **短腿是这个宇宙的问题**：11 个长牛 ETF 上，1/N 多空毛 Sharpe 只有 0.15，
   而只做多是 0.56——做空需要「会跌的资产」（v2 用期货）。
3. **它的价值是条件收益**：标普最差 10% 的交易日，日均跌幅 −15.4 bps，60/40 是 −122.1 bps；
   2022 年 +13.9%，而 60/40 是 −16.6%。**它是保险，不是发动机。**

另一个实操结论：**ETF 层容量只有 50 万美元**（约束来自 FXY），所以真实实施必须在期货市场。
